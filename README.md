# OIBSIP — Oasis Infobyte Internship (Python Development)

Projects completed for the Oasis Infobyte Python Programming internship.
Each task lives in its own subfolder with its own README, dependencies,
and run instructions.

## Tasks

| # | Project | Description |
|---|---------|-------------|
| 2 | [BMI Calculator](Python-Task2-BMICalculator) | Tkinter desktop app that calculates BMI, classifies the result, and stores history in SQLite. |
| 3 | [Random Password Generator](Python-Task3-RandomPasswordGenerator) | Tkinter app that generates cryptographically secure passwords with configurable length and character sets. |
| 5 | [Chat Application](Python-Task5-ChatApplication) | Multi-room, real-time chat app — threaded TCP socket server and a tkinter GUI client, with SQLite-backed accounts and message history. |

## Tech Stack

Python, Tkinter, SQLite, sockets/threading, matplotlib.

Each subfolder includes its own `requirements.txt` — install per-project as needed:

```bash
cd Python-Task2-BMICalculator
pip install -r requirements.txt
```
